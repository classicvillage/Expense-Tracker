How Native Android Apps Read SMS Automatically

The mobile architecture behind Walnut, Axio, and SMS Organizer

Web browsers run inside a sandboxed environment that prohibits direct access to your phone's SMS inbox for privacy (otherwise malicious websites could steal bank OTPs).

To make this 100% automatic in a native Android app, the app registers a BroadcastReceiver in its AndroidManifest.xml: 

<!-- AndroidManifest.xml -->
<uses-permission android:name="android.permission.RECEIVE_SMS" />
<uses-permission android:name="android.permission.READ_SMS" />

<receiver android:name=".SmsListener" android:exported="true">
    <intent-filter>
        <action android:name="android.provider.Telephony.SMS_RECEIVED" />
    </intent-filter>
</receiver>

When any bank sends a transaction SMS, Android wakes up the receiver in the background and runs the same regex parser we built in JavaScript: 

class SmsListener : BroadcastReceiver() {
    override fun onReceive(context: Context, intent: Intent) {
        // Extract SMS body from intent
        val messages = Telephony.Sms.Intents.getMessagesFromIntent(intent)
        for (sms in messages) {
            val text = sms.displayMessageBody
            val sender = sms.originatingAddress
            val parsed = parseExpense(text)
            saveExpenseToDatabase(parsed)
        }
    }
}
